# Shared Latent Characteristic Anchored Hash Codes Generation for Efficient Fine-grained Image Retrieval
This project is a pytorch implementation of the submitted manuscript. For fair comparison, codes for data loading are directly cited from SEMICON (SEMICON: A Learning-to-Hash Solution for Large-Scale Fine-Grained Image Retrieval. ECCV 2022: 531-548.).

## Training 
1. Download corresponding datasets, and update the data root in "train.py".
2. Train the model with 
```shell
python train.py
```
